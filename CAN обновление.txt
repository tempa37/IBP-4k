Обновление через CAN происходит в следующем формате:

1) список CAN ID для обновления 
	CAN_FLAG_SLAVE_OS = 0x4E1 - Отсылается мастером, при получении этой команды stm32 стирает сектора для ОС баттарейного блока
	CAN_SLAVE_OS = 0x4E2 - с этим CAN ID
	CAN_ACK_BLOCK = 0x4E3
	CAN_FLAG_MASTER_OS = 0x4E4
	CAN_MASTER_OS = 0x4E5
